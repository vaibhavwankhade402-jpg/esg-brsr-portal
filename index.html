1. Individual company

Upload one sustainability report or BRSR. The portal attempts to find common ESG disclosures, then lets you review and edit the evidence before scoring.

Machine-readable PDF works best.

2. Compare two companies

Upload two BRSR or sustainability reports. The portal creates a side-by-side evidence table, BRSR principle coverage check and comparable/non-comparable flags.

How reuse works

  1. Upload the new company's BRSR or sustainability report.
  2. Review the automatically found evidence and source page numbers.
  3. Enter or correct the actual value and target/benchmark where required.
  4. Use the fixed 12-indicator scoring rules to calculate the score.
  5. For two companies, the same evidence architecture is applied side by side.
Important: this is a student-designed academic tool. Automatic extraction is a candidate-finding aid, not a substitute for reading and verifying the source report. Missing or non-comparable data is never silently treated as zero.

Scoring rules

Target attainment: MIN(100, Actual ÷ Target × 100).

Benchmark attainment: MIN(100, Actual ÷ Benchmark × 100), where higher is better.

Outcome rubric: 0 / 25 / 50 / 75 / 100 based on outcome, scale, trend and evidence.

Governance rubric: 0 / 25 / 50 / 75 / 100 based on structure, performance, compliance and assurance.

Reliability and scalability

  • Automatic extraction is candidate extraction only.
  • Source page and evidence text are retained for review.
  • “Not comparable” is available when metrics differ.
  • The framework, weights and formulas remain fixed across companies.
  • Sector-specific modules can be added later.
